# Widget App Testing Guide

This document provides information about the testing setup and how to run tests for the widget application.

## Testing Framework

This project uses the following testing tools:

- **Jest**: A JavaScript testing framework.
- **React Testing Library**: Testing utilities for React components.
- **@testing-library/jest-dom**: Custom Jest matchers for DOM assertions.

## Test Structure

Tests are organized alongside the source code in `__tests__` directories.
